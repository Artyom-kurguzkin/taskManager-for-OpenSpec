## What the industry does
- Collapsed rails keep every primary action as an icon with a tooltip (VS Code activity bar, Linear sidebar, Material navigation rail: https://m3.material.io/components/navigation-rail/guidelines).
- Saved views: Linear "Views", Jira "Saved filters", GitHub Projects views tab: a named snapshot of filters/grouping/sort, opened from a list, "Save as new" vs "Update" (https://linear.app/docs/custom-views, https://docs.github.com/en/issues/planning-and-tracking-with-projects/customizing-views-in-your-project/managing-your-views).
- Issue sub-items counting bugs: Jira counts sub-tasks and sub-bugs in one progress bar with a type icon; GitHub sub-issues progress counts every child.
- Property pickers offer existing values first, "create" last (GitHub labels, Notion select).

## Decisions
- Bug notes count toward the subtask tally while unresolved; shown in the subtask list with a bug mark; resolving the bug resolves the row. Stored as notes, not duplicated into tasks.md (one place per piece of information).
- Saved arrangements are per machine in the user settings file, per project, named; the current BoardOptions stays the live one.
