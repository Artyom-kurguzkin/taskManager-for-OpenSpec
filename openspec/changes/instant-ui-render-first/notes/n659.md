# Diagnosis: UpdateText read tripped its own gate guard

`Commands.UpdateText` holds the path gate (`HoldPath`) and then called `Queries.ReadText`, whose new guard does `gate.Wait(0)`; the semaphore is not re-entrant, so the holder never recorded `LastSeen` and `WriteLocked` refused as stale (`EventsAreNeverLost` red, plus the new test `HolderOfTheGateRecordsItsRead`). Fix: `UpdateText` is the only caller inside a hold, so it uses a new `Queries.ReadTextHeld` that records without taking the gate; the public `ReadText` guard is unchanged.
