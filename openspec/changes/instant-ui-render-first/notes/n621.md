# Decision

Nothing blocks the UI thread: lock waits, MoveOver retries, the duplicate scan, git status and feature rescans run on the thread pool and come back through InvokeAsync; Workspace.Notify gets a lock around resolving and scanned.
Photino runs every event and render on one native thread, so any wait there freezes paint and input together; Notify already runs from three threads with plain fields.
