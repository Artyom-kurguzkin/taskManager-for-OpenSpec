# Decision

Found in the real app: a status pill picked just before closing wrote the yaml but the drain still hit its 5 s limit, because the refresh after each command (Notify -> SideNav.Redraw -> InvokeAsync) blocks forever once the window loop has ended, and it held the write queue. Fix: DoLater releases the queue and signals "landed" before the refresh, and Drain waits for the write, not the refresh; new red-then-green test "Drain does not wait for the refresh a closed window can no longer run".
