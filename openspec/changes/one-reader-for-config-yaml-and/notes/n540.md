# Decision

One boundary rule for #wiN, #nN: at most 9 digits, no letter/digit/underscore after the number, none before the # (and no second #). [[doc]] needs a closing ]] on one line.
This is GitHistory's old rule (the strictest) made the only one, so #wi12a, foo#wi12 and ##wi12 stop linking in notes and stop being renamed on renumbering; it also fixes int.Parse overflow on huge numbers. GitHistory is handed the matcher per call (OpenSpecStoreApi.MentionsItem), no reference to OpenSpecStore.
