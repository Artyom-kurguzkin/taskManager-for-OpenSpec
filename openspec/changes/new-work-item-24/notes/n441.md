# List header: row cell shows above the column headers (cause)

Reproduced on the hidden desktop (1280 px, list, colour by status, table scrolled right and down). Cause: `.tbl-wrap .hdr-path` (the 28px strip above the th, sticky top:0, z-index 3, paper background) is only as wide as the wrapper's visible width (1212 px), while the table is 1456 px and scrolls sideways; the strip is not sticky horizontally, so when scrolled right its band ends and the row cells scrolled up behind the sticky th show in the open band at the top right (th are sticky at `top: 28px`). Fix: every `thead th` paints the 28px band above itself in the paper colour (`box-shadow: 0 -28px 0 var(--paper)`).
