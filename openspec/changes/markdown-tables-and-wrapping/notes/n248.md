# Excel-like table grid

Answer to #n237. With the caret in a table, a grid lays over the raw lines: column letters and row numbers, click or drag to select, double-click or type to edit, Tab / Enter / arrows, copy and paste as tab-separated text. The ribbon grew: move row up/down, move column left/right, sort A–Z / Z–A, delete and align on the selection, and Edit as text / Grid. The markdown stays the stored form. I ran the full flow against the merged build with real key events (insert, align, move, sort, edit, paste, delete column, text mode and back, Esc): every step wrote a clean table. 33 node tests, 593 suite tests pass. Known: the ribbon covers the note's title line while the grid is open; Home/End/PageUp/PageDown and Ctrl-arrows are not handled in the grid.
