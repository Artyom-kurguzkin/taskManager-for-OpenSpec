# Decision

Cause: the table helper was attached once per editor (keyed by note id / "desc"), but Blazor makes a new textarea when an entry arrives above the editor (reproduced on the hidden desktop: appending an event to events.log while editing gave textarea #2 with no helper). Fix: Worklog and NotePage track the textarea's ElementReference.Id and attach again whenever it differs; the script also opens the grid for a "/table" already there when it attaches.
Why not key the editor or listen on the document: markup keying is outside this chunk; the per-element attach stays the one mechanism.
