# Plans show their tables, and nothing runs off the window

The app's markdown setup had no table support, so a table stayed raw |---| text, and that long unbroken text made the page wider than the window. Tables and bare links are now on everywhere markdown is shown (plans, descriptions, notes); tables get a light header and row lines and scroll on their own when wide, and long words break. Checked on the hidden desktop with the 9 Nov plan: the chunk table renders, no raw pipes, nothing wider than the window, light and dark.
