# Proposal

## Why

A plan opened in the app showed its tables as raw "| # | Chunk |" text, and that unbroken text pushed the page wider than the window, so lines were cut off on the right.

## What Changes

- Markdown tables and bare web addresses render everywhere the app shows markdown (plans, descriptions, notes).
- A wide table scrolls on its own; a long word or address breaks instead of widening the page.
