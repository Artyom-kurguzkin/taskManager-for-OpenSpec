# Changed period hides instead of greying

While a changed period is set, items not created or changed in it are hidden on the board, list and calendar; the date picker gets a "Show all" option that clears it, replacing the × beside it.
Why: the user asked on 10 Nov ("instead of coloring-grey - hide all items that have not been modified within selected period. the calendar picker should also have an option show all"); one clear control instead of two.
