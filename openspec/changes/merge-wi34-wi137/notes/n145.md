# Description into the worklog, Related into Linked tasks

- The description is the worklog's first entry, above today. Shift-click it for **Edit**: it turns into an editor in place, saves when you leave it, and a pasted image still becomes an attachment linked at the caret.

It goes when the worklog closes, and in split view it sits above the list's blocks.
