# Proposal

## Why

The app has only a light and a dark look. The owner wants custom themes: the stylesheet arranged so a theme is one block of values, two more themes (Novita from the finance-tools project, Ayu Mirage from the owner's VS Code), and the chosen theme kept as a user setting.

## What Changes

- The stylesheet's colours go through one set of named values, so a theme is one block that sets them
- Two more themes: Novita and Ayu Mirage
- Settings offers the themes; the choice is saved per user and applied at start
