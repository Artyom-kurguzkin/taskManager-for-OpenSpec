# Logging merged and checked: hand-off

The three logging chunks (terminal output, crash capture, page side) are merged in the working tree, uncommitted, on top of b0fc4bb.

**What changed for you**
- Started from a terminal, the app now prints its log lines there. Photino's own message dump is off.
- Every action on a page writes one `ui` line naming the page, the action and the item.
- Every failure the app can see leaves a line: unhandled and unobserved exceptions, the window dispatcher, a failing component (the page shows a message with a Reload link), page script errors, the file watcher's timer, and the WebView2 process ending.
- A window that freezes for 30 s leaves an Error and a dump of every thread's stack.
- At start, an earlier run that did not exit cleanly is named: stopped by a publish, Windows shutdown or sign-out, or killed or crashed. It is no longer called a crash by guess.
- "Open current log" in the side menu opens this run's log. When `.log` has no default program on Windows, it opens in Notepad instead of the "Open with" picker.
- New package: Microsoft.Win32.SystemEvents 10.0.5. It tells the app about Windows shutdown and sign-out.
