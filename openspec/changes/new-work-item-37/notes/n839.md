# Decision

One logging seam (Microsoft.Extensions.Logging, already in the shared framework the app hosts Kestrel from), two providers: the console when a console is attached (`dotnet run`) and one file per run, `%LOCALAPPDATA%/RepoTaskManager/logs/run-<yyyyMMdd-HHmmss>-<pid>.log`, newest 20 runs kept.
End-to-end traces through `ActivitySource("RepoTasks")`: an activity per UI command, MCP tool call, queued write and scan, its trace id and duration on every line, so one id follows a press from the UI through the store to the watcher. Debug lines (reads, scans, renders) only with `RTM_LOG=Debug`.
Rules out a logging package: the framework's abstractions and a 40-line file provider cover it. Plan: DevResources/plans/in-progress-items-2026-11-20.md (chunk logging).
