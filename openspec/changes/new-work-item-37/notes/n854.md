# Hand-off: one log per run, console under dotnet run, traces end to end

Where the logs are: `%LOCALAPPDATA%\RepoTaskManager\logs\run-<yyyyMMdd-HHmmss>-<pid>.log`, newest 20 kept; the same lines go to the console when one is attached (`dotnet run`). `RTM_LOG=Debug` adds the file-watcher scans. Line format `HH:mm:ss.fff LEVEL traceId category: message`; exceptions follow on their own lines. The crash log stays and its text also goes to the run log; the agent endpoint's log lines now land in the run log too.

Files: TaskManager/Helpers/AppLog.cs (new: factory, file and console sinks, retention, activity listener), TaskManager/Program.cs, TaskManager/Api/AgentEndpoint.cs (SharedLogProvider replaces FileLoggerProvider), TaskManager/Components/RepoPage.cs (`ui.command`), TaskManager/AppState/Workspace.cs (`write` in DoLater, `scan` in Notify), TaskManager/Mcp/BoardTools.cs (`tool <name>`), TaskManager.Tests/LoggingTests.cs (new, 6).

Black box (hidden desktop, RTM_LOG=Debug): changing #121 from Backlog to Planned gave one trace id across `ui.command` start, `write` start/stop (272 ms), `scan` start/stop and `ui.command` stop (459 ms). Sample: tests/out/report/wi178-run-sample.log; console capture: tests/out/report/wi178-console-capture.txt.
