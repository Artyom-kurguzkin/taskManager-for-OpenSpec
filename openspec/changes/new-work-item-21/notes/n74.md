# Plans and attachments folders for every project

Settings now has a "Folders of <project>" row for each open project, with a Plans and an Attachments field. Empty uses the defaults, DevResources/plans and local/task-tracking. A change applies to that project only: its openspec/REPO-TASKS.md is rewritten and names both folders, and its .gitignore gets the attachments folder.

Also fixed: a pasted image could be written into another open project. The app looked up the note in one project but took the folder from whichever project a background refresh had just made active. The note then listed a file that wasn't in its repository, which matches #wi99's missing screenshot. Attachment writes now use the note's own repository. That screenshot itself could not be recovered.

Checked in the real app, light and dark: with two projects open, a paste into a demo2 note landed in demo2's own folder.
