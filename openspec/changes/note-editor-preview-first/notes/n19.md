# 28 Oct — spaces in the editor

Typing a space in the design pane looked like nothing happened: the next letter landed in front of it. The pane needs `white-space: pre-wrap` (Radzen's own stylesheet, which the app does not load, sets it) so a trailing space is kept and the caret stays after it. Added to app.css with the pane's block-spacing rules.
