# Sandbox research done: options and open questions

Research for #n136 (Claude Code in a Docker sandbox: project files only, web search, PowerShell and bash, MCP, no `openspec/`, reachable from the desktop app and VS Code) is in `DevResources/plans/claude-sandbox-research-2026-11-25.md` (about 70 source links, three parts: runtime, attaching the clients, this repository).

Main findings: the board tools are reachable from a container over the app's HTTP endpoint with no app change (token and repo path in headers; the token works on every repository); `openspec/` can be made unwritable with a read-only mount but not unreadable while `.git` is mounted; both clients attach over SSH; the build should work on Linux, the real-app check cannot. Recommended: a purpose-built Docker container, with a short trial of Docker Sandboxes (`sbx`).

Nothing is built. Nine questions for the owner are at the end of the file's summary.
