# The tools now feed the worklog

With #wi94: every change a tool call makes is recorded in the item's worklog under the agent's name, `board_get` returns the worklog, `board_update` links documents (`docs`), and `board_note` takes an optional title (its first line otherwise). The server instructions and the guide, now v13, tell agents to keep the worklog current. The guide refresh test was renamed (it no longer names a version); its link here is updated.
