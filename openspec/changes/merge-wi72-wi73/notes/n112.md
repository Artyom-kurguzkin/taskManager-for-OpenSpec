# Guide v12: the conventions file now starts with the MCP tools

The file the app writes to `openspec/REPO-TASKS.md` moved to version 12 with #wi121. Its new first section tells an agent how to see whether the `repo-tasks` tools are loaded, how to turn them on (the `.mcp.json` entry with this machine's app path, `claude mcp add`, `--serve` with the token file for HTTP-only clients) and how to use them; the hand rules that were the whole file before are now the fallback. The old section 0 is 0a. Older copies are refreshed when the app opens the project.
