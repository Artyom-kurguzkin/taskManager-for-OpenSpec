# 5 Nov — deleting a feature others still spec

Deleting a feature is no longer refused when open work items still have delta specs for it. The dialog names those items ("#wi90, #wi85 and #wi89 still describe it in their specs; those spec files are deleted too"), and the app deletes their delta folders with the feature and keeps each change valid. Archived changes are left alone. Checked on the hidden desktop against the "workspace" feature that failed before.
