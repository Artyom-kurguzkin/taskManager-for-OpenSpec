# Startup measurements: R2R builds vs today's exe

Median ms from process start, 5 runs (a second warm pass of 7 runs in brackets). The machine was shared with two other agents, so runs vary a lot.

```
exe                       main   serving MCP   page-up   (warm)
Debug build               226    3194 [1331]   4216 [2163]
today (dist, no R2R)       -     1409 [4579]   2156 [6415]
R2R small (fw-dependent)  216     1683 [916]   3208 [2170]
R2R full (self-contained) 104     954 [1336]   2178 [2175]

cold-ish (fresh repo copy per run)
Debug build               107    7032          9514
today                      -     7454          8056
R2R small                 141    8014         10574
R2R full                  146    9425         10582
```

"today" predates the run log: it has no `main` mark, `serving MCP` comes from its agents log and `page-up` is when WebView2's debug port first lists the page. Sizes: R2R small exe 32.2 MB (today 14.3 MB), R2R full exe 172.5 MB. Warm page-up has a floor of about 2.15 s for every build; the cold-ish runs are 7-10 s whatever the exe, so the repository load, not JIT, dominates the first window.
