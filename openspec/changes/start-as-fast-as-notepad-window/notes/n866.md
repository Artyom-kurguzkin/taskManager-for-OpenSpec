# Decision

The board's "updated" stamp reads events.log for its times and a note's head only when that note's file is newer than the newest time found (newest file first, 10 minutes of slack); an archived change with a log is taken from the log alone.
Why: a note is never created after its file was written, so older notes cannot move the answer; the stamp keeps its meaning (worklog, not file times) and a checkout that rewrote every file still reads each head, exactly as before.
It rules out using file times for "updated" (a checkout would make every item "updated now"); the board therefore does read events.log, which the brief said it would not.
