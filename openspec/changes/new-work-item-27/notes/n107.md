# Paste images straight into a description

Pasting an image into the description editor saves it as pasted-<date-time>.png in the project's attachments folder under wi<item>/ (no note needed), puts a ![](path) line at the caret so you see where it went, and saves the description at once. In view mode the image shows inside the description, scaled to the tile. The file goes to the repository the item lives in even when another project is active, and the folder is kept out of git like note attachments. Only the first image on the clipboard is used. Checked in the real app, light and dark: the link appeared at the caret, the file was on disk, and the image rendered after leaving the editor. Pasting into a note still attaches as before.
