# Decision

The fallback is implemented: when git cannot name the sides (markers edited after the merge commit, no merge commit, octopus, no git history) the hunks in the file are the sides, the text outside is the base, and ours wins what both changed. Rebase, cherry-pick and revert in progress are not repaired (ours/theirs mean other things there).
Why: a file still gets rebuilt instead of pausing for a hand edit; the conflict event says that git's sides were not available.
