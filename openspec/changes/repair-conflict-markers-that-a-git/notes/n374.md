# Decision

Repairable kinds are .openspec.yaml, tasks.md, notes and events.log only; proposal.md, specs and any other file with markers still pause. A merge in progress is repaired but the sync stays paused (MERGE_HEAD check comes first), since git owns that state.
Why: those are the files with a field-wise rule (the brief's list); a whole-file "newer wins" on prose would silently drop text.
