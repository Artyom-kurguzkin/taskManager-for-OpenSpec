# Decision

GitHistory gets a GitWatcher (driven through Raise/RaiseError + injected TimeProvider in tests), Uncommitted(contentVersion) with no directory walk, and `git --no-optional-locks status`.
Why: git status can rewrite the index, which the watcher would read as a change and loop; the content version comes from the host because GitHistory must not reference OpenSpecStore. The parameterless Uncommitted() keeps its walk.
