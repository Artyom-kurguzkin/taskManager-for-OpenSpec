# Decision

MoveAttachments moves the files first, rewrites references second and removes the empty old folders last; a collision suffix is `-2` like AttachFile (not ` (2)`); a note whose frontmatter cannot be read is not touched and is named in the message.
Pruning last means an interrupted run always leaves the old folder, so running again finds it and finishes the references; `-2` keeps one naming rule for attachments.
