# Large local files are re-read lazily, small ones kept

Scan hashes files over 256 KB as a stream and keeps no bytes; uploads and base copies re-read them one at a time and refuse a file whose hash changed meanwhile. Files up to 256 KB keep their bytes from the scan, so the board behaves exactly as before.
A lazy re-read of every file would make a board sync fail whenever the app writes a file mid-sync.
