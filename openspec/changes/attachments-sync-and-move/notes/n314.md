# One trash link for both syncs

Attachments' trash and the single trash link: the attachments sync keeps its trash under state-attachments/trash. The one link opens the board's trash when only that exists, the attachments' when only that exists, and the project's sync folder (which holds both state folders) when both exist.
Why: the engine owns its trash folder per state folder, so one link cannot point into two; opening the parent keeps one link and reaches both, only when both have content.
