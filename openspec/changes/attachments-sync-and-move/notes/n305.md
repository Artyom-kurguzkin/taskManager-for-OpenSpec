# Decision

Attachments folder is stored as one inline line `attachmentsDir: <folder>` at the end of the x-rtm block in config.yaml, read through ReadRtmSection and written through WriteRtmBlock (WriteRtmSection can only write the key in block form); the default removes the line.
Inline reads better in a git diff and a pull; the section writer would have produced `attachmentsDir:` plus an indented value.
