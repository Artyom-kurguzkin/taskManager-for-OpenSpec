# Too-large paths are left alone like links; the cap is an AsyncLocal seam

A path over the object cap (local file or remote object) goes to SyncReport.TooLarge and into the planner's linked-paths set, so it is neither uploaded, downloaded nor taken for a deletion. The cap is StorageLimits.ObjectMax, overridable per async flow (OverrideObjectMax) so tests use 300 KB without affecting parallel tests.
BoardStorageException stays sealed and carries an internal IsTooLarge flag, because an existing test asserts its exact type for an oversized manifest (which stays a failure).
