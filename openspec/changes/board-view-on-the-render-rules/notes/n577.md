# Decision

Cards redraw on every Load (a version in the card key), not only when their own item changed. A card's cached callbacks capture the load's project and columns (drop places by `col.Items`), so a card kept across loads would act on stale columns.
The tests-failing flag is read once per Load (not per card render); a new results file is picked up at the next load.
