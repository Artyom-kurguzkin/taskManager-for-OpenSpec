# Root cause found and reproduced red. The board and the side menu read and save t

Root cause found and reproduced red. The board and the side menu read and save the view options under Workspace.Root, the process-wide active project. Opening a card or adding an item in another project (Workspace.Open) makes that project active, so the board switches to its record and the hidden list looks cleared; the first project's record is untouched. A single-project walk (add item, list, calendar, item page) keeps the list in a test, so the fix is in the shared place: a view project that only an explicit tab switch changes.
