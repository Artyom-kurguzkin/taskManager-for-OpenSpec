# Decision

A chosen settings folder is remembered in settings-location.txt next to the default file; an unusable pointer falls back to the default file and the Settings page says so. RTM_SETTINGS still means one exact file with no pointer.
A new build or reinstall must find the moved file, and a vanished drive must not stop the app or hide that settings are missing.
