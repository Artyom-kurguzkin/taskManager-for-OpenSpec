# Merge is a per-user view setting, never a project edit

Merges are BoardOptions.Merges [{name, statuses}] in the user's settings file, per board, matched by exact status string per project; no project's config.yaml or item changes.
Why: the projects are separate repositories shared with other people, and "completed" vs "Completed" is how this one user wants to look at them.
