# Where "+ status" puts the status, and which project

A new status goes at the end of the project's list but before Completed (a new optional parameter of WorkItemsApi.AddStatus; the Settings page keeps appending at the end), so it shows left of the Completed column. On the shared header row of several projects "+ status" asks which project with a choice dialog (each project, and "All projects" which adds it to every project that lacks it); a per-project row (rows view, swimlanes, projects with different columns) adds to its own project without asking.
Why: Completed means archived and belongs last; one extra click on the shared row is the simplest correct way to name the project, and "All projects" covers the common case of wanting the same column everywhere.
