# Multi-project status columns are the union of the projects' lists

With several projects grouped by status, the shared header row has one column per distinct status (first project's order first), after merges; a project shows an empty column for a status it lacks, and a drop there is refused with a message.
Why: it keeps the one shared header row (where Shift-select and Merge live) when projects have different lists.
