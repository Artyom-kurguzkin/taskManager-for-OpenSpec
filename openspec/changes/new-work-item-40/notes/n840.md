# Decision

The table editor (md-table.js, md-editor.js, the /table overlay) leaves this app entirely; the markdown textareas stay plain. In window-manager it becomes the Win+Alt+T hotkey: copy the focused control's selection, edit it in a grid, paste it back as a markdown pipe table (Markdown, txt) or an HTML table on the clipboard (Word, Google Docs).
A clipboard round trip is the one way that works in every app; HTML on the clipboard is how Word and Google Docs take a table. Typing /table in any app is a follow-up (it needs the key hook to watch typed text).
Plan: DevResources/plans/in-progress-items-2026-11-20.md (chunks table-out here, table-in in window-manager).
