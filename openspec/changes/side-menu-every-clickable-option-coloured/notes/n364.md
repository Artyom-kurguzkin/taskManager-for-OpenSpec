# Decision

Show all hidden does not open collapsed projects, and a collapsed project's items count in no column header.
The owner folds a project to set it aside; unhiding must not bring its items back into the counts or the columns.
It reverses the fold part of today's show-hidden fix; hidden columns, rows, projects and deleted items still come back.
