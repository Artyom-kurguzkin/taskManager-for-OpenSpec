# Proposal

## Why

In the side menu the dropdown values (sort by, groups, subgroups, colour, contributor, period) and the changed date/time selector look like plain text, so nothing says they can be clicked. "show all hidden" does nothing when clicked, and the collapsed menu has no way to reach it.

## What Changes

- Every clickable value in the side menu is a coloured pill or underlined: the six dropdown values and the changed date/time selector become pills.
- Pill colour by value: "none" (and "any time", "everyone", the neutral choice) is grey; any other value is yellow.
- "show all hidden" shows the hidden columns, rows, projects and items when switched on, and reads "show all hidden".
- The collapsed menu has an icon button for show all hidden, pressed when on.
