# A call's repository is an AsyncLocal scope; tool calls use guests, not tabs

OpenSpecStoreApi.InRepo / GitHistoryApi.InRepo / WorkItemsApi.ActingAs return IDisposable scopes backed by AsyncLocal overlays over the process-wide current and actor; Workspace.In and BoardTools.Run use them, so nothing process-wide is swapped any more. A repository the app does not have open becomes a guest (own Repo, version and generation, no watcher, in a Guests map outside Repos), so a tool call never lands in OpenRoots; an open one is used as is, so its version moves and the board sees the write.
Rules out Open(keepOthers) plus release after the call (it would flicker the open set and race with the tabs) and passing an explicit root through every Api (a signature change in every module).
