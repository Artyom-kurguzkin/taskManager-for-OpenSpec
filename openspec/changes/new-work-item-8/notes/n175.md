# Analytics v1: what a chart is

Analytics is a fourth view beside Board, List and Calendar. A chart is layout (column, bar, line, stacked column) + X-axis (status, feature, label, priority, contributor, or time by week) + optional group by + count of work items or subtasks; charts are saved per board, drawn as inline SVG, and follow the board's filters.
Why: it is GitHub Projects' Insights model (layout, X-axis, group by, Y), which the item asks for; over-time charts read the worklog, so there is no new storage and no chart library.
