# Proposal

## Why

The board answers "what is where"; it does not answer "how much, and how is it moving". The user asked for a new view, Analytics, similar to GitHub Projects' Insights: charts they can customise to query the board.

## What Changes

- A fourth view, **Analytics**, beside Board, List and Calendar.
- A chart is a layout (column, bar, line, stacked column), an X-axis (status, feature, label, priority, contributor, or time by week), an optional group by, and a count of work items or of subtasks.
- Charts are saved per board; two come by default: "Items by status" and "Status over time" (twelve weeks, replayed from the worklog).
- Each chart is edited in place (title, the four choices, Delete); "+ Add chart" adds one.
- Charts are inline SVG in the board's colours and follow the board's contributor and period filters.
