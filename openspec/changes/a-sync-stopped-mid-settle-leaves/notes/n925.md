# Warn on close while files settle; the next app repairs a half-uploaded folder

The app warns with a popup when it is closed (or synced) while board files are still settling; if a partial folder reaches the storage anyway, the next app instance that reaches the storage repairs it (the merging computer finishes the upload, the other holds the folder back and does not renumber).
Why: owner, 2026-11-27: "app should show a popup warning. if it indeed happens, the next app instance reaching storage should be the ones fixing it".
