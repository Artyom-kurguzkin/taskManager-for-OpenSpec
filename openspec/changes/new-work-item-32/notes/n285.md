# Deletions still sync, but sync never erases a file

Deletions keep travelling through the storage, and a file the sync removes on a computer is moved to a trash folder in the app's data (kept 30 days) instead of being erased; an edit that loses to a delete is also kept as a conflict note.
Archiving, merging and renumbering are deletions underneath, so banning them would show archived items twice and trigger the duplicate-id repair. Agreed with the owner on 12 Nov; rules out both a ban and "an edit always beats a delete".
