# Reserved number blocks are deferred

No number blocks per computer in the first version: two computers may still allocate the same id offline, and the repair from #wi159 renumbers the later one after the sync.
The repair already exists and is tested; blocks need a counter in the storage and a change to id allocation for a collision that is rare with one user.
