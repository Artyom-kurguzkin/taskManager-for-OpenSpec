# The board stays in git; a pull is an outside edit

The board stays in `openspec/` and in git; sync treats what a pull or checkout changes as an outside edit, except content the storage has already moved past, which is never uploaded.
Agents and history keep working as now, and an old branch cannot push stale tasks to the other computers. Sync pauses while a git merge is in progress.
