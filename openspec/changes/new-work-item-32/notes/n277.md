# Decision

A storage that lost its manifest while this computer remembers one is treated as "upload everything again", not as a mass delete.
Reading it the other way would delete every local file on a small board (the brake only starts above 10 files); re-uploading is safe and converges.

Also: a local file that changed while a sync ran is left alone and keeps its old base, so the next sync merges instead of overwriting the edit. A delete is stamped with the time of the sync (a deleted file has no write time).
