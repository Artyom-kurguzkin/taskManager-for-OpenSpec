# Which overwrites are trashed

Trash only where bytes would be lost: every local delete (all of DeletedHere) is moved to StateFolder/trash/<UTC stamp>/<path>; of the overwrites only a non-text clash that the storage wins is copied there first.
Only-storage-changed (local = base), stale replace (local = an earlier version in the manifest history) and first connection (backup/) keep the old bytes elsewhere; a merge lists the dropped side in Conflicts; a non-text clash that the local side wins uploads the local bytes, so the storage's objects keep the other one.
