# events.log outside changes merge without a base

An events.log changed outside the app is merged with the storage's live log with NO base, so the union of lines applies even when only this computer changed it; a merge that adds nothing to this computer's log is reported as Uploaded, as before.
Why: with the base equal to the storage's log the generic merge lets the local (old) log win whole, which would roll the log back.
