# Sync whole files through a manifest, R2 first

Whole files are synced with a three-way merge per file type; one manifest object is replaced only if unchanged, and the first store is Cloudflare R2 behind an S3-compatible provider.
Operation logs and CRDTs cost far more and make the plain files a by-product; R2 is free at this size and its API also covers S3 and MinIO.
