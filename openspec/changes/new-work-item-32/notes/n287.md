# A skipped path forces a manifest re-read

After a path was skipped (the trash move failed, or the file changed under the sync) the state now keeps the previous StorageVersion instead of the new one.
Why: with the new version saved, the next sync answered NotModified from the saved entries (the old, pre-skip ones), so the tombstone was never seen again and the retry did nothing.
