# Repository settings are a proposal; sync needs approval on each computer

A storage named in the repository's settings is not used until this computer approves that exact provider and address; keys are bound to the address they were entered for; endpoints must be https; links inside the board are never followed.
The security test proved that a cloned repository, or a pull that changes the address, could send the board to a folder, network share or host the user never chose. The owner approved fixing all findings on 12 Nov; both fix chunks started.
