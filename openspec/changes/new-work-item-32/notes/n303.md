# Cause of the settings-save flake

The SecretStaysOnThisComputer flake: `BoardStorageSettings` read credentials.json / approval.json with `File.ReadAllText` (share mode Read only) while `WriteAtomic` did `File.Move(temp, target, overwrite: true)` once with no retry; a reader on another thread (the sync service resolving the storage) holding the file open made the Move throw UnauthorizedAccessException out of SetValue. Reproduced red with a hammer test, fixed by shared-mode reads (ReadWrite|Delete), a retrying atomic write (8 tries, growing delay), a lock over the settings class's own file access, and failures returned as (false, message).
