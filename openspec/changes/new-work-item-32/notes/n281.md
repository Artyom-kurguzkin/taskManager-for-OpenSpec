# Chunk git integrated

The engine now treats old content that a checkout brings back as stale (the storage's version returns, nothing is uploaded) and returns Blocked while a git merge, rebase, cherry-pick or revert is in progress or a board file holds conflict markers. The sync, merge and storage test classes in the main tree:

```
Passed!  - Failed: 0, Passed: 69, Total: 69
```

Known limits: only the last 20 versions of a path are remembered, so older content coming back counts as an edit; the stale rule does not apply on a first connection. The host chunk (settings, triggers, conflicts on the item) is still running.
