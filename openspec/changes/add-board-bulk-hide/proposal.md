# Proposal

## Why

The selection action bar on the board only offers Merge, which needs two or more cards and is a one-way combine. There was no way to hide several items at once; hiding one at a time from each item's own page doesn't scale once more than a couple are selected.

## What Changes

- The action bar gets a "Delete (hide)" button, enabled with one or more cards selected, that hides every selected item the same way the per-item "Delete (hide)" button already does (reversible via "show hidden" + Restore).
