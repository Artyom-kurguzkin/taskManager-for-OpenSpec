# 26 Oct — list view rebuilt on the data grid

The list is a RadzenDataGrid dressed in the app's own stylesheet, laid out like Asana / Linear / ClickUp lists: no frame, 40px one-line rows, a quiet sticky header (sort mark, funnel and hide × appear on hover; the whole header reorders by drag; a 16px handle on the column edge resizes, with a guide line down the table), status / label / priority as colour pills, a status group's name in its band.

Selection is the board's: Shift / Ctrl / ⌘-click a row (no tick boxes), arrow keys move the selected rows, a drag from any cell selects a cell rectangle while a still click still works the cell. The compact switch hides every subtask and nothing else; groups collapse one at a time from their chevron. A column is hidden from its header × and comes back from the side menu's Hidden list.

Verified in the real app over CDP in both themes. Commit e102c24 carries the first part; the rest is uncommitted on main.
