# Merged from #wi101 Remove a project x rudementary button

## Why

Each project row in the repository menu had its own × button next to the eye. It looked rough and made removing a project too easy to hit by accident.

## What Changes

- The project rows in the repository menu lose their × button.
- "Remove a project…" at the end of the menu stays the one way to remove a project: it asks which one.
