# Twelve colours, given out in order

Colour by feature or by contributor used six colours picked by a hash of the name, so features shared colours. There are now twelve (six new: rose, teal, sand, green, indigo, orchid, each with a dark shade), handed out in the order the board lists the features or people, so the first twelve never repeat; past twelve they cycle. A filter no longer recolours anything, and the legend and the cards always agree. The legend shows up to twelve values before "+N more".

Checked in the real app on the hidden desktop, light and dark: twelve features and eleven people, all different, cards matching the legend. With several projects open each project hands out its own colours, so one person can differ between projects.
