# The list nests rows inside columns

With columns by status and rows by feature, the list now shows each status first and the features inside it, then the items. A status header counts all its items. Dropping a row onto a feature group inside a status sets both. Collapsing a feature under one status leaves it open under the others. Without rows the list is unchanged; the calendar still puts rows outside columns.

Checked in the real app on the hidden desktop, light and dark: Backlog then its features, one feature collapsed under Backlog only, and #wi108 dragged onto Planned / Track work items changed its status and feature on disk.

"+ Add item" under a feature group adds the item to the column only, without that feature, as before.
