# Decision

Opening another project never swaps the board's view: only the first project and choosing a tab set it.
`Workspace.Open` sets the view root to the project just opened, so the board shows that project's saved options (no arrangement) and Research goes back to its default place. Keeping the view root keeps the user's arrangement; the new project's statuses land where its own list puts them.
