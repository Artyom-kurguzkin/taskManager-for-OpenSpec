# view-root chunk started: mechanism differs from the brief

Chunk started. Mechanism found: `Workspace.Open` already keeps `viewRoot` (it only sets it for the first project or when the old one is gone). The real cause is `Workspace.OpenTab`, which both the tab click and the "Open another repository" / Settings import call: it sets `viewRoot = root` unconditionally, so an imported project B takes over the view and the board reads `Settings.Board(B)` (no arrangement). Fix goes in `OpenTab`: choose the view only when the project is already open (a tab choice); a newly added project leaves the view alone.
