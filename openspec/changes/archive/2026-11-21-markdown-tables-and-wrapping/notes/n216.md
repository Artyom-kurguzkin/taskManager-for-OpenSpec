# Table helper: /table grid plus an in-table bar

`/table` at the start of a line opens a Word-style rows × columns grid; with the caret in a table, a small bar adds or deletes rows and columns, and Tab / Shift+Tab move between cells with the table re-aligned. In every markdown editor of the app.
Why: n157 asks for /table and Word-like editing; Obsidian's Advanced Tables and Typora's generator do the same on plain markdown, so the file stays plain text.
