# Decision

Grid overlay for markdown tables is in (md-editor.js, md-table.js, app.css table helper block). Verified in the hidden app on the feed note editor, the description editor and the note page, light and dark.

Decision: the textarea keeps the focus in grid mode and drives the grid by keydown; only cell editing moves focus to an input inside the overlay.
Why: the note page ends the edit on a textarea blur, so a window-capture listener hides the blur whose relatedTarget is in the overlay.
