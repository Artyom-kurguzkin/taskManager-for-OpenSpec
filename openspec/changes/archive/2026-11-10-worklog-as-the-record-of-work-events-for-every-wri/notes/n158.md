# Decision: rename and merge are events

Decision: a rename is a `title` event (`Old -> New`) and a merge logs `merged-from` on the surviving item, one per source (`#wi<id> <title>`), shown under the Events filter.
Why: the user asked for both on 2026-11-10 ("renaming a work or merging other ones into it should be considered events too"); the survivor already inherits the sources' events, so one line per source is enough to see where its history came from.
