# Chunk columns integrated: the user's column order wins

Merged from worktree chunk-ag. Cause: with two or more projects the shared header's columns had no drop handler, so a drop "in front of Blocked" bubbled to the head-row handler meaning "after the last column", and that end position was saved as the arrangement; Left/Right never moved a selected board column, and with one project the headers could not be Shift-clicked. Fixed: the drop handler on the shared-header columns, Left/Right on the board (Up/Down in the list) through MoveColumns, Shift-click on every header, and Arrange with inPlace so a status the saved order lacks goes where the projects list it.
