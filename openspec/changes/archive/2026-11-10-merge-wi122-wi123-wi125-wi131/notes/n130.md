# Merged from #wi122 List view groups rows outside columns

## Why

With columns set to status and rows set to feature, the list grouped by feature first and by status inside it. Columns are the upper grouping; the rows should be grouped inside each column.

## What Changes

- The list groups by project (when several), then by the column field, then by the row field inside each column.
- A column's header counts all its items; a drop on a row group lands in that column and that row; collapsing a row group inside one column leaves the same row open in other columns.
- The calendar keeps rows outside columns.
