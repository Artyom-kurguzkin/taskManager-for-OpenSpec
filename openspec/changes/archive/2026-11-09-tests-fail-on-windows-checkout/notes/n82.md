# All 18 were line endings

Every one of the 18 failures came from the test fixtures being checked out with CRLF on a machine with core.autocrlf on. A one-line .gitattributes pins TaskManager.Tests/Fixtures to LF on every checkout, and a guard test fails if any fixture ever contains a carriage return. Checked in a fresh worktree: 18 red before, all green after.

A checkout that already has CRLF fixtures needs them re-checked out once: delete the Fixtures folder and run git checkout on it.
