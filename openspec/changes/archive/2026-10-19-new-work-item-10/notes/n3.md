# New note

While Microsoft officially promotes .NET MAUI / Blazor Hybrid for desktop apps, MAUI lacks official Linux support. Coupling Tauri with Blazor WASM provides a highly efficient alternative that natively supports Windows, macOS, and Linux without bundling a massive Chromium runtime
