# 31 Oct — features can be renamed

"Rename feature…" in a feature column's menu asks for the new name (starting from the current one). The spec folder or config.yaml entry is renamed, every change's delta folder for it moves too (archived ones included), and work items keep their links. The column keeps its place if you had moved it. Checked in the real app, light and dark.
