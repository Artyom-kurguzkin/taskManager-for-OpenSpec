# Each project keeps its status list in config.yaml

Each project's statuses are an ordered list in openspec/config.yaml under x-rtm.statuses; missing means the built-in default list. Backlog, In Progress and Completed are fixed (put back if a hand edit drops them, never removed or renamed in the app).
Why: the list travels with the project like lanes and filesDir do, and an agent in any worktree reads the same list.
