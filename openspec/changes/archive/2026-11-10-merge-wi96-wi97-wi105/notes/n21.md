# 31 Oct — every open project on one board

The store now keeps every tab open at once (a content version and a file watcher each; module caches per repository), and `Workspace.In(repo, …)` reads or writes another tab without changing the active one. The board stacks a block per project under one shared header row when the columns align (status / label grouping), with a chevron to collapse and a menu to hide (the side menu's Hidden list brings it back). Cards move within their project; a drop into another project is refused with a message; opening another project's card makes it the active one. The list groups by project, then column.

Checked in the real app with two demo repositories as tabs, light and dark.
