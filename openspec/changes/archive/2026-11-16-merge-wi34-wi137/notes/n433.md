# A moved subtask is logged once per subtask in both feeds

Moving subtasks to a new item logs "subtask-moved 1.3 -> #wiM" in the source and "made-from-subtask 1.3 of #wiN" in the new item, one event per subtask, by its number before the move, with the actor; making it a dependency does the same.
Why: #n412 asked for a log in the feed; per-subtask lines let a reader find each one, and the number before the move is the one the source's feed already used.
