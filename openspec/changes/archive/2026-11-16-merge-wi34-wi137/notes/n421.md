# Subtask made from a note ends in its #nN

A subtask made from a note, decision or bug ends in " #nN" (the owner's own suggestion), and the Linked tasks view shows that as a "from #nN" link instead of the raw text.
Why: the reference survives renumbering and moving, which the converted event's subtask number does not; the existing "(created subtask)" marker lives in the note body, not in the subtask, so it cannot point back.
