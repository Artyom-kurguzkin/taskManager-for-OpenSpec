# Linked tasks: main list with a side rail

The Linked tasks view becomes subtasks as the main list (two thirds, groups with progress, open first, done folded per group) and a right rail with Waiting on, Waiting on this and Related; option 1 of the five mockups, chosen by the user on 11 Nov.
Why: subtasks are what the view is used for; the relations are short lists that read best beside them, as in Linear and GitHub.
