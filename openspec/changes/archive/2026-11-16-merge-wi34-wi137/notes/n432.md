# Links between a note and its subtask are marked by a CSS class, both ways

"from #nN" on a subtask opens the worklog at the note, and a converted entry's "subtask N" opens Linked tasks at the subtask; the target gets a "flash" class (a CSS fade, a static mark under reduced motion).
Why: it needs no timer, so the tests are deterministic (the class and the scroll call are asserted); the owner asked for the first direction, the second was cheap.
