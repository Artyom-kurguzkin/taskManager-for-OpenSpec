# Every project shows its location

Settings no longer shows one repository path at the top. Each open project has its own row, headed by its name, starting with its location (the full path, selectable) and a "Show in folder" button, then its Plans and Attachments folders. The top row is now "Open another repository": an empty path box with Browse… and Open, which adds that project and switches to it. Checked in the real app, light and dark, with two projects open.
