# The open item can move to its own window

The split button on the item page is now a menu: "Beside the list", "Item only" and "Separate window". "Separate window" opens the item in a second app window titled "#wi<N> <title>" and sends the main window back to the board. That window shows only the item page, no side menu, split menu or back button, and never writes the settings file, so the two windows never fight over it. Edits made in one window show in the other. On a narrow window the menu offers "Item only" and "Separate window". Checked on the hidden desktop, light and dark: the second window opened on the item, and a title typed there showed in the main window.

Known limit: the separate window can show the board for a moment before the item page appears.
