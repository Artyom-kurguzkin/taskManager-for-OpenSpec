# Proposal

look at the last log

if there is enough space, when a work item is expanded, by default work ite details should poen in half-screen view - the left-hand side should be the rest of the work items in list view.

## Why

Opening an item hid the list; going back and forth to compare or pick the next item cost a navigation each time.

## What Changes

- On a window at least 1400px wide an open work item renders beside the list: the list on the left with the open item's row marked, the item on the right. Clicking another row opens it on the right and the list keeps its scroll and filters.
- A toggle on the item page hides the list; the choice is remembered. Narrower windows show only the item.
