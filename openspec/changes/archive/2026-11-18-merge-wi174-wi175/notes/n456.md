# Decision

A commit touches an item when it changed a file in the item's change folder (archive date prefix dropped); read from the one cached git log over openspec/changes that GitHistory already runs, per HEAD. Uncommitted = git status paths under openspec/changes, cached under HEAD plus a fingerprint of those files, since dirty state does not move HEAD.
Rules out one git show per commit and a git process per render.
