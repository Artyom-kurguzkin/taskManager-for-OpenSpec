# Proposal

## Why

In the List view the Organise options still read "columns" and "rows", the words of the board. The list has no columns to group by: grouping by status duplicates the Status column the row already shows, and "columns" cannot even be set to none. The Settings page is the one soft sheet still drawn inside a rounded frame, which wastes space and does not match the other screens.

## What Changes

- In the List view the two options are called "groups" and "subgroups". Both offer "none" and both default to none, so a fresh list is flat and ordered as sorted.
- The board keeps "columns" and "rows" with their defaults; a saved view keeps what it had.
- The Settings page is a plain soft sheet like the other pages: no border, no rounded frame.
