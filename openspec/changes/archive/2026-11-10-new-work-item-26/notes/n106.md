# No outer frame on the calendar, item and note pages

The calendar, the work item page and the note page no longer sit in a rounded outer frame: their header and tiles sit straight on the page, like the list. The tiles keep their borders. The calendar's left pane and header now use the page colour so no white block shows where the frame was. Settings keeps its frame; the document (plan) page loses it too, as it uses the same page shell. Checked light and dark.
