# Editors fill their tile; a note's title is its own

The description and note text boxes now fill their tile while you edit, with no border, outline or background of their own: the tile is the frame. A note's title is kept in its frontmatter (title:), so renaming a note no longer rewrites the first heading of its text; notes without a title still read it from their first heading. New notes start with an empty body. The agent guide says where the title goes. Checked in the real app, light and dark: the description box filled the tile to within its header row, the note box likewise, and renaming a note changed only its title: line.
