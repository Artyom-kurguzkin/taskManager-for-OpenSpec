# The note editor is now the description's text box

Clicking a note's text opens the same plain text box the work item description uses, with no toolbar and no design or source modes. It autosaves shortly after you stop typing. Clicking outside saves at once and shows the rendered note again. Pasting an image still attaches it, and "Edit in…" and the links and attachments tiles are unchanged. The Radzen markdown editor and its styles are gone. Checked in the real app in light and dark.
