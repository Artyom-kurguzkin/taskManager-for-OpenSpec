# Modules answer through a host-installed cached read

Each module keeps no cache but has a plain uncached read plus a one-time `Use...` hook (WorkItemsApi.UseBoard, NotesApi.UseNotes, FeaturesApi.UseReader, LinkedTestRunsApi.UseReader, GitHistoryApi.UseReads) that the host installs once (AppState.Caches.Install, from Program.cs and the test Begin()).
Why: the modules' own commands, rules and the tool calls read the board hundreds of times per click; without the hook every Get(id) would parse every folder. With no hook installed a module reads afresh on every call.
