# Decision

Structure follows the BI reference solution's written rules: the 3am placement rule, no cross-cutting infrastructure, and a host with no Services/. No shared Platform or Cache module: each module owns its files, its cache and its change signal. The host has ApplicationState, BackgroundProcesses and Components.
Proposed earlier without reading the reference plans; the owner rejected it. The only addition beyond the reference is one base component in the host, for render control.
