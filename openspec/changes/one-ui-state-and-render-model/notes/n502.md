# The caching research is back (sources from 2025-2026). Recommendation: one Cache

The caching research is back (sources from 2025-2026). Recommendation: one Cache module. Sources (openspec files, config.yaml, git HEAD/index/refs, settings, per-file stamps) carry version counters, confirmed by fingerprints. A Memo.Get(key, deps, compute) helper recomputes only when a dependency moved, and skips the update when the new value is equal (early cutoff). UI components subscribe to memos, and no file or git IO runs in render paths (guarded in Debug). HybridCache was rejected: it is async-only, made for multi-server setups, and has no file dependencies.
