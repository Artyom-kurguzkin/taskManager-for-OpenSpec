# The open-source code research is back: 12 projects read at their current branche

The open-source code research is back: 12 projects read at their current branches. The current aspnetcore main still renders after every event and still treats complex parameters as changed, so version stamps, IHandleEvent and keyed subscriptions are the current model, not old hacks. TanStack Table v9 replaced whole-table re-renders with per-row selector subscriptions. Patterns found: rows as markup (QuickGrid), a version-stamp gate (Oqtane, Excalidraw), keyed selection deltas applied as CSS (VS Code, Plane), and non-rendering events (FluentUI rows).
