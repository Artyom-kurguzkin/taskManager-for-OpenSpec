# Principles research and the app map are back. Principles: Blazor (.NET 10 source

Principles research and the app map are back. Principles: Blazor (.NET 10 source) still renders after every handler and treats records as changed, so render skipping must be our own convention. The recommendation is one base component (IHandleEvent, RenderKey, Select subscriptions, render counter) plus an immutable store with keyed subscriptions. App map: SideNav's bubbling nav onclick, IO in render paths (GetWarnings, GetLanes, NotePage image base64, the ExaminePanel fingerprint walk), and an uncoalesced Workspace.Changed fan-out (6-8 renders, 3 Loads per change). Waiting for the open-source code research and the two screen probes.
