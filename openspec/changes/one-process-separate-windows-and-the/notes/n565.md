# Separate windows are merged into main: one PhotinoBlazorApp per window, built on

Separate windows are merged into main: one PhotinoBlazorApp per window, built on the UI thread. App-wide services are shared, while UiService, AppMode, pickers and frame are per window. A window with AppMode.Repo runs its handlers and loads inside Workspace.Scope(repo). Workspace notices go to every window through Say(). Real app: no second process for the window, and an edit in window 2 shows on window 1's board (tests/out/wi188).
Open:
- BoardSyncService notices still go to the main window only.
- BoardPage's PickProject has no window argument.
- A closed window's provider is not disposed (Photino #149/#158).
- The same item can open twice.
- In dark mode, focused input text in the separate window looked almost invisible; to check.
