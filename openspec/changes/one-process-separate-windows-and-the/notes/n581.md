# Decision

Stale-write guard: the store's LastSeen (what the app last read of each file) is now per caller scope. A tool call runs inside OpenSpecStoreApi.AsCaller() with a fresh record; the window keeps the process-wide one. So an agent's write never updates the window's record, and the window's later write on an older read is refused as stale (same message the watcher path gives) instead of silently replacing the agent's text. Rejected: one shared record (the agent's write would make the window's old read look current), and a per-agent-session record (a call needs nothing from a previous call; board_update already has the revision check).
