# Second-instance detection no longer probes /health

Cause: AgentEndpoint.StartAsync decided ServedByAnotherWindow with `McpShim.VersionAtAsync(port)`, an HTTP /health probe with a 2 s timeout that swallows every exception into null; under load the probe timed out and the second instance reported a problem instead. Fix: the decision is now `AgentEndpoint.HeldByAnotherWindow(home, port)`: this home's server.json (written by the first before its StartAsync returns) names that port and a live pid. No probe, no timing. Added two tests (silent TcpListener holder passes; missing/other-port/dead-pid file is a Problem).
