# Serving fix merged. "A second app instance leaves the first one serving" failed

Serving fix merged. "A second app instance leaves the first one serving" failed once in regression because ServedByAnotherWindow was decided by a 2 s /health probe that timed out under load. AgentEndpoint.HeldByAnotherWindow now reads the home's server.json and checks the pid is alive on that port, with no network and no timing. Two tests added (a silent TcpListener holder is recognised from server.json alone; a foreign holder, stale file or dead pid is a Problem). Behaviour change: a port held by another program now shows as a Problem, not "another window".
