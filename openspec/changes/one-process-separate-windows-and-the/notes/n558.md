# Decision

A separate window reads and writes its own project through a per-window scope (AppMode.Repo, applied around Load and every event handler in RtmComponent), not through process-wide SettingsStore.ReadOnly/OpenRepos overrides, which are removed.
Why: the repository is per call already, so a second window stays on its item's project when the main window switches tabs; the process-level hacks would have hit the main window too.
